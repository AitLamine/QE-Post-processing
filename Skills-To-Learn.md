# Skills to learn

Prioritized list, from most urgent (to continue the current project) to optional.

## Level 1 - essential, consolidate first

| Skill | Why |
|---|---|
| JavaScript / TypeScript | Base language of the app (Next.js) |
| Git / GitHub | Already used (push); refine further (branches, PRs) |
| Linux/bash command line | Partly acquired via QE/HPC, keep reinforcing |
| React (components, hooks, state) | Foundation of everything built on the interface side |

## Level 2 - for the rest of the HPC project

| Skill | Why |
|---|---|
| Next.js (App Router, API routes) | Framework already in use in dft-postprocessing |
| HTTP/REST | Understand how the front talks to the backend |
| SSH/SFTP and key management | Core of the Marwan automation |
| Databases (basic SQL, Postgres) | To store job state (status, history) |

## Level 3 - to secure and professionalize

| Skill | Why |
|---|---|
| Basic security (secrets management, input validation, permissions) | Uploads and HPC credentials are handled |
| Asynchronous programming (promises, retries, polling) | Already encountered with the Workflow SDK |

## Level 4 - optional, to go further

| Skill | Why |
|---|---|
| Docker | Package a script so it runs anywhere |
| CI/CD (GitHub Actions) | Automate tests/deployments |
| Cloud/serverless concepts | Understand Vercel's limits vs a classic server |

## Practical advice

Don't learn this in isolated courses - keep learning "as you go" on the actual project (ask
questions, understand the choices). That is the most effective method for someone with limited
time alongside a PhD thesis.
